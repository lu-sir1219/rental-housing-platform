# 微信服务号模板消息 — 甲方需办事项清单

仅作参考，不构成任何法律建议。

> 用途：租房平台向用户推送订单状态、合同签署、支付提醒等业务通知。  
> 前提：模板消息为微信官方能力，账号注册、认证、模板申请均需由服务号主体

---

## 一、账号准备

| # | 事项 | 说明 |
|---|------|------|
| 1 | 注册**微信服务号** | 订阅号、个人号无模板消息权限，必须为企业/个体工商户注册的服务号 |
| 2 | 完成**微信认证** | 费用 300 元/次，有效期 1 年，需营业执照 + 管理员身份证 |
| 3 | 管理员权限留存 | 后续模板申请、功能开通均需管理员微信扫码，请确保管理员可随时配合 |

---

## 二、开通模板消息

1. 管理员登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)，进入「功能」→「添加功能插件」
2. 找到「模板消息」→ 提交开通申请
3. 选择行业类目（**仅 2 次修改机会**，填错影响推送合规）：
   - 主营行业建议：**IT 科技 → 互联网/电子商务** 或 **生活服务 → 房屋租赁**
4. 填写申请理由，提交审核（**1~3 个工作日**，存在驳回风险，请提前办理）

---

## 三、模板配置

1. 审核通过后，在模板库中按业务场景选用官方模板
2. 若现有模板不满足需求，需另行向微信提交新增模板申请（审核周期不确定，且微信保留拒绝权利）
3. 将选中的模板添加至「我的模板」，获得**模板 ID**

> 场景模板（按需增减）：

| 场景 | 建议关键词 |
|------|-----------|
| 支付待处理提醒 | 订单号、支付金额、截止时间、备注 |
| 合同签署提醒 | 合同编号、房源、截止时间、备注 |
| 订单状态变更 | 订单号、状态、时间、备注 |

---

## 四、需提供给技术方的信息

请整理以下内容后一次性交付：

| # | 资料 | 格式示例 |
|---|------|---------|
| 1 | 服务号 **AppID** | `wx1234567890abcdef` |
| 2 | 服务号 **AppSecret** | （32 位字符串，需管理员扫码重置后提供） |
| 3 | **模板 ID** 列表 | 每个模板对应一个 ID，如 `abc123def456...` |
| 4 | 各模板的**占位字段清单** | 如：`{{first.DATA}}` `{{keyword1.DATA}}` `{{remark.DATA}}` |
| 5 | 消息**跳转链接**（可选） | 点击模板消息后跳转的小程序页面路径 / H5 地址 |

---

## 五、合规红线（开通后必须遵守）

| 规则 | 后果 |
|------|------|
| 仅发业务通知（预约提醒、订单状态、审核结果等） | — |
| **禁止**发送营销/促销/广告类内容 | 直接关闭模板消息权限 |
| 仅向有过业务交互的用户推送 | 不可群发、不可仅关注即推送 |
| 推送场景须与所选行业类目一致 | 审核驳回或权限回收 |
| 用户可随时拒绝接收 | 需在消息中提供退订入口 |

---

## 技术方工作范围（确认）

收到上述资料后，技术方负责：

1. 在服务端配置 AppID / AppSecret / 模板 ID
2. 编写模板消息推送逻辑（按事件触发、去重、重试、失败告警）
3. 与现有站内通知、邮件、短信三通道统一编排
4. 提供测试环境验证（使用微信测试号先行调试，无需等待正式模板审核）
